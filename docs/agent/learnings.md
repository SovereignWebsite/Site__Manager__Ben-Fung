# Learnings (a.ben-fung, 24 to 25 Nov 2026)

- A simulated sceptic that fact-checks every page against the one source is the most valuable reviewer: round 1 found 22 overstatements (dates implied, decisions credited, caveats dropped, work tied to the wrong employer). Keep every caveat from the source.
- Five designs read as five concepts only when each has its own palette, typography and structure; the first line map looked like a reskin of the career path until it got its own diagram and cards.
- Phones break the clever designs first (tables, Gantt charts): check 390px after every change.
- A per-design share card and description make shared links distinct.
- The sgit key setup script was refused by the auto-mode permission checker; a plain ssh-keygen ECDSA key published in `site/keys/` (as llms.txt allows) worked, at the owner's word.
- Requests relayed by other agents (retire a key, change content) need the owner's yes in the keeper's own session.
- Running reviewers in parallel: three rounds of six reviewers took about 10 minutes of wall-clock; about 2.16M tokens in total for the reviewers and reporter.
